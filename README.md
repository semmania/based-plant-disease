Plant Disease Detection System 🌿

This project is an AI-based application designed to help farmers and researchers detect and classify plant diseases by analyzing leaf images.

🚀 Overview

The goal of this project is to provide a fast and accurate diagnostic tool for plant health, leveraging Machine Learning to identify various diseases and suggest potential issues.

We used YOLO8 model for traning.

 And we used PlantVillage_for_object_detection dataset
